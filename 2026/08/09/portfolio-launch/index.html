个人作品集正式上线

发表于2026-08-09|更新于2026-08-09

作品集地址：shiq.me

这是最早的一个作品集，从第一版到现在，改动都记在下面这份更新日志里。

更新日志

  • V5.7 · 图片仓库上一页导航：在图片仓库顶栏新增“← PREV”按钮，可切换到上一个地区，同时保留“NEXT →”的下一地区浏览功能。
  • V5.6 · 纯白跨页隔离：关于我与图片仓库之间切换时，禁用旧页面层的滑动，完整保留全白白幕转场。
  • V5.4 · 更快的空白关闭预览：图片预览的淡入、模糊与缩放时长统一缩短 30%；移除 CLOSE 按钮，点击大图以外的空白区域即可退出。
  • V5.3 · 玻璃淡入与日志倒序：大图预览新增模糊淡入与毛玻璃背景；更新日志按最新至最早显示；移除阳朔图库中的已选照片。
  • V5.2 · 本地资源加载修复：部署到网站时保持深链接资源路径；直接双击本地 index.html 时不再丢失样式、动效与图片。
  • V5.1 · 图片预览缩放动效：点击缩略图后，照片从原位置展开至沉浸式大图；关闭时缩回点击的照片位置。
  • V5.0 · 浏览器历史路由：主界面、关于我与每个地区图片仓库都拥有可分享网址，浏览器返回、前进会按原路线恢复页面。
  • V4.3 · 网页标签彩蛋：打开网站的前五秒显示“原神？启动！！”，随后自动切换回作品集标题。
  • V4.2 · 反向纯白翻页：返回主页时改为向左翻页，白幕完整覆盖内容后再切换，避免照片提前露出。
  • V4.1 · 首页署名更新：将首页署名更新为“CODING BY GPT5.6-SOL”，移除原有 VIBECODING 后缀。
  • V4.0 · Cloudflare 发布包：完成首页动效性能收敛与标题幅度调整，整理为可直接部署的 Cloudflare 静态发布版本。
  • V3.11 · 标题旋转幅度微调：将主页立体标题的鼠标最大旋转幅度降低 40%，减少文字层叠穿插感。
  • V3.10 · 动效性能优化：停止不可见的 WebGL 背景副本，流线降至 30fps；立体标题改为轻量鼠标驱动渲染。
  • V3.9 · 显性立体文字：进一步拉高默认旋转角度与层叠厚度，未移动鼠标时也可清楚看见标题立体动效。
  • V3.8 · 强化立体标题动效：加深标题层叠深度与自动旋转幅度，让首页文字动效更清晰可见。
  • V3.7 · 标题动效与无漏帧翻页：加入原生立体文字兜底，并确保白幕完全覆盖后才切换页面，避免反向翻页露出照片。
  • V3.6 · 标题动效安全加载：重构 Depth Text 的加载方式：静态标题始终保留，确认动效成功渲染后才切换至立体文字。
  • V3.5 · 地区标题字距统一：将所有“地区▪城市”标题统一为带间距的“地区 ▪ 城市”排版。
  • V3.4 · Depth Text 标题动效：主页主标题接入 React Bits 的立体文字层与鼠标视差动效。
  • V3.3 · 浙江标题字距：将“浙江 ▪ 杭州”分开排版，避免地区标题的字符视觉重叠。
  • V3.2 · 纯白翻页过场：保留左右翻页轨迹，但在内容替换的中间阶段仅显示完整纯白页面。
  • V3.1 · 纯白页面转场：统一以纯白遮罩切换页面与图片仓库 NEXT，消除下一页内容提前闪现的问题。
  • V3 · 匿名建议箱：在关于我页加入匿名建议表单，并接入 Cloudflare D1 保存每一条反馈。
  • V2.4 · 地区浏览顺序：将主页与仓库循环顺序调整为桂林、广州、厦门、长沙、北京、武汉、浙江、长城、天津、足球赛。
  • V2.3 · 流线兼容渲染：保留原版 Threads，并加入高兼容 Canvas 流线层，确保本地浏览也能稳定看到动效。
  • V2.2 · 官方 Threads 动效：移除额外视觉兜底层，只保留 React Bits 原版 WebGL 流线动画。
  • V2.1 · 流线主页持续运行：加强主页动效可见性，优化仓库导航并记录版本更新。
  • V2.0 · 主界面与关于我：重构沉浸式首页，加入固定导航与独立联系页。
  • V1.1 · 仓库快速浏览：新增地区循环切换，让图片浏览更连贯。
  • V1.0 · 作品集正式上线：建立地区索引、全景封面与完整图片仓库。

这个站一开始只是想找个地方放几张片子，后来慢慢长成了现在这样。作品集之后有新动静，也会继续记在这里。

最后提一句：这个作品集是用我自己的域名 shiq.me 部署的，一直开着。里面「关于我」那一页留了个匿名建议箱，照片选得不对、动效太晃、哪一页打不开，都可以去里面给我提建议，不用留名字。
